# Skills de diseño

Guarda aquí las skills de diseño que se vayan a utilizar en el proyecto. Para cada una, crea una carpeta con su propio archivo `SKILL.md` y añade los recursos que necesite.

Ejemplo:

```text
design-skills/
└── nombre-de-la-skill/
    ├── SKILL.md
    └── recursos/
```

Al añadir una skill, documenta su propósito, cuándo utilizarla y las instrucciones necesarias para aplicarla.
